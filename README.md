# کفو (Kafv) · سامانه همسرگزینی و پرسشنامه آنلاین آشنایی

سامانه تحلیلی ارزیابی چندمعیاره و پرسشنامه آنلاین آشنایی و ازدواج، طراحی‌شده برای دانشجویان و پژوهشگران دوره دکتری.

---

## ساختار سامانه

1. **فرم عمومی (ویژه متقاضیان و مخاطبان آنلاین)**:
   - هر فردی که آدرس سایت را باز کند، صرفاً فرم وزین، متین و آکادمیک معرفی و پرسشنامه را مشاهده می‌کند.
   - بازدیدکننده به هیچ‌یک از پرونده‌ها، امتیازها یا اطلاعات سایر افراد دسترسی ندارد.
   - اطلاعات پس از تکمیل، مستقیماً برای شما ثبت شده و در صورت تنظیم وب‌هوک/ربات تلگرام، پیام فوری به گوشی شما ارسال می‌شود.

2. **پنل اختصاصی مدیریت (محافظت‌شده با PIN)**:
   - دسترسی با کلیک روی «ورود مدیر» و وارد کردن پین (پیش‌فرض: `1374` - قابل تغییر).
   - شامل داشبورد تحلیلی، ماتریس اوزان (MCDA)، نمودار راداری ۶ بعدی، بورد CRM مراحل آشنایی و قالب‌های آماده پیام در لینکدین یا از طریق معرف.

## نحوه پوش (Push) کردن کدها به ریپازیتوری گیت‌هاب

پوشه پروژه را در سیستم خود باز کنید و دستورات زیر را در ترمینال اجرا نمایید:

```bash
# ۱. راه‌اندازی گیت (اگر انجام نشده است)
git init

# ۲. افزودن فایل‌ها و ثبت کامیت
git add .
git commit -m "Initial release of Kafv matchmaking system"

# ۳. تنظیم برنچ اصلی و اتصال به ریپازیتوری شما
git branch -M main
git remote add origin https://github.com/renullza/khanomamko.git

# ۴. ارسال به گیت‌هاب
git push -u origin main --force
```

## نحوه دیپلوی رایگان (Deployment)

### روش اول: دیپلوی فوق‌العاده سریع با Vercel (توصیه‌شده - ۱ کلیک)
1. وارد سایت [vercel.com](https://vercel.com) شوید و با اکانت GitHub خود لاگین کنید.
2. روی دکمه **Add New Project** کلیک کرده و ریپازیتوری `khanomamko` را انتخاب (Import) کنید.
3. بدون نیاز به تغییر هیچ تنظیمی، روی **Deploy** کلیک کنید.
4. ظرف ۲۰ ثانیه یک آدرس اختصاصی امن (مانند `https://khanomamko.vercel.app`) دریافت می‌کنید که می‌توانید در بیو، لینکدین یا پیام‌ها به اشتراک بگذارید.

---

### روش دوم: دیپلوی روی GitHub Pages
1. در فایل `package.json` در سیستم خود، اسکریپت بیلد را اجرا کنید:
   ```bash
   npm run build
   ```
2. وارد بخش **Settings** ریپازیتوری `https://github.com/renullza/khanomamko` شوید.
3. در منوی سمت چپ روی **Pages** کلیک کنید.
4. در بخش **Build and deployment**:
   - گزینه **Source** را روی **GitHub Actions** قرار دهید.
   - تمپلیت پیش‌فرض **Static HTML** یا **Vite** را تایید کنید، یا پوشه `dist` را در برنچ `gh-pages` آپلود فرمایید.
5. آدرس شما به صورت `https://renullza.github.io/khanomamko/` فعال خواهد شد.

## دریافت فوری پیام به تلگرام هنگام پر شدن فرم توسط متقاضی

از آنجا که گیت‌هاب پیجز یک هاست استاتیک است، برای اینکه اطلاعات پرشده توسط افراد در مرورگر خودشان نماند و **بلافاصله به گوشی شما برسد**:

1. وارد پنل مدیریت سایت خود شوید (با پین `1374`).
2. روی آیکون دیتابیس (پشتیبان‌گیری و تنظیمات) در نوار بالا کلیک کنید.
3. اطلاعات یک ربات تلگرام رایگان را وارد کنید:
   - به ربات `BotFather@` در تلگرام بروید و دستور `newbot/` بزنید تا یک توکن (Token) رایگان بگیرید.
   - به ربات `userinfobot@` بروید تا شناسه عددی (Chat ID) خود را بگیرید.
   - هر دو را در کادر تنظیمات وارد و ذخیره کنید.
4. از این پس هر زمان فردی فرم را پر کند، متن کامل پاسخ‌ها بلافاصله در تلگرام شما ارسال می‌شود!
